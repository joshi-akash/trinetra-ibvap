## Item 1.1: Cryptographic Merkle Epoch Root Archiving & Append-Only Tombstone Logging

### Context & Evidentiary Proof
In border security and military custody (BSF / MHA), video surveillance evidence must withstand scrutiny in judicial and court-martial inquiries. Demonstrating that video files were not tampered with, deleted, or fabricated requires tamper-evident proof.

### Technical Amendments:
1. **Per-Camera Hash Chains**: Each detection and alert event generates a SHA-256 leaf hash linked to the prior hash in the stream (`prev_hash : current_leaf_hash`).
2. **Hourly Merkle Epoch Rollups (`archive_epoch_index`)**: At the close of each operational epoch (hourly), the complete set of event hashes is computed into a binary Merkle tree root and persisted to `archive_epoch_index`.
3. **Per-Alert Notarization Token**: Every active alert generated by `package_builder.py` is signed with a deterministic token:
   $$\text{Token} = \text{SHA256}(\text{"TRINETRA\_NOTARIZED:"} \parallel \text{alert\_id} \parallel \text{clip\_sha256} \parallel \text{timestamp} \parallel \text{camera\_id})$$
4. **Append-Only Database Invariant**: The primary `entity_log` table is strictly immutable. SQL `UPDATE` queries are forbidden.

## Item 1.2: Bounded Probabilistic Threat Formula with Visibility Floor

### Context & Alarm Fatigue Mitigation
Standard CCTV systems suffer from alarm fatigue due to grazing cattle, windblown vegetation, and darkness noise. Threat calculation is formalized as a compound probabilistic union multiplied by visibility compensation.

### Formulation:
$$P_{\text{threat}} = \min\left(1.0, (P_{\text{geo}} + P_{\text{beh}} - P_{\text{geo}} P_{\text{beh}}) \times \min\left(1.0, \frac{P_{\text{det}}}{\tau_{\text{vis}}}\right)\right)$$

Where:
- $P_{\text{geo}}$: Spatial breach probability derived from Shapely Point-in-Polygon intersection.
- $P_{\text{beh}}$: Behavioral anomaly probability (crouching, sprinting, prone crawl, threat prop).
- $P_{\text{det}}$: Object detection confidence from YOLOv8s.
- $\tau_{\text{vis}}$: Adaptive visibility floor dynamic threshold calculated from Laplacian variance ($\tau_{\text{vis}} \in [0.40, 0.80]$).
- **Active Alert Threshold**: Requires $P_{\text{threat}} \ge 0.70$ and 5 consecutive tracking frames when visibility compensation is active.

## Item 1.3: 92% Emergency FIFO Storage Purge via `os.unlink()`

### Context & BOP Hardware Protection
Remote Border Out Post (BOP) Video Analytics servers run unattended 24/7 on finite local SSD storage without cloud offloading. If disk space reaches 100%, database corruption and system crash occur.

### Technical Amendments:
1. **Emergency Trigger Watermark**: When filesystem usage hits $\ge 92\%$, the background `StorageCleaner` (`backend/app/storage/cleaner.py`) automatically activates.
2. **FIFO MP4 Unlinking**: Unlinks oldest `.mp4` video clips in FIFO order via `os.unlink()` (executing in $< 1\text{ ms}$) until disk usage is relieved down to $\le 80\%$.
3. **Tombstone Recording (`media_tombstone_log`)**: Prior to unlinking, an immutable tombstone record is recorded preserving the original clip filename, SHA-256 hash, eviction timestamp, and disk usage percentage.
4. **Integrity Retention**: All rows in `entity_log` remain completely untouched. The evidentiary audit trail remains legally verifiable via the two-tier `/api/alerts/verify-integrity/{id}` endpoint.
